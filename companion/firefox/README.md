# JD Turnstile Companion — Firefox

Installable **`.xpi`** (not a temporary debugging add-on).

```bash
cd companion
./install-firefox.sh
# or: ./install.sh → [1]
```

- Auto-update feed: [`updates/firefox.json`](../../updates/firefox.json) (requires Mozilla-signed XPI)
