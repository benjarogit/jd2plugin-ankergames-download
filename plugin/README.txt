AnkerGames — JDownloader 2 plugin
=================================

No AnkerGames login required. Manual install only.
No Core.jar patch — Turnstile HTML ships in plugins/components/.

1) Find your JD folder (installer or portable — path differs per PC):
     Windows:     find-jd-home.bat
     Linux/macOS: ./find-jd-home.sh

   JD root   = folder with JDownloader.jar + Core.jar
   Plugins   = <JD-root>/jd/plugins/

   If the helper finds nothing:
     - Start JD once, or open the shortcut's file location
     - Search for JDownloader.jar / Core.jar
     - Portable: check where you extracted JD
     Details: ../README.md  or  ../README.de.md  ("If nothing is found")

2) Copy plugin files into <JD-root>/jd/plugins/ (hoster, decrypter, components).
   Full steps: ../README.md  or  ../README.de.md

3) Then install the Chromium companion (root README).
